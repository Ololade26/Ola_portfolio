# Ola_portfolio
Personal portfolio website for Azeez Victor Ololadé — includes CV, skills, projects, and contact details.

## 🌐 Live Demo
Visit the live portfolio at: [Portfolio Website](https://ololade26.github.io/Ola_portfolio/)

## 📥 How to Download This Portfolio

### Method 1: Download as ZIP
Click the button below or visit the releases page:
- **[Download Latest Version (ZIP)](https://github.com/Ololade26/Ola_portfolio/archive/refs/heads/main.zip)**

### Method 2: Clone with Git
```bash
git clone https://github.com/Ololade26/Ola_portfolio.git
cd Ola_portfolio
```

### Method 3: Download from Website
Visit the portfolio website and click the "Download Portfolio" button in the hero section or footer.

## 🚀 Quick Start

After downloading, open the `index.html` file in your web browser:

1. Extract the ZIP file (if downloaded as ZIP)
2. Navigate to the folder
3. Double-click `index.html` or open it with your browser
